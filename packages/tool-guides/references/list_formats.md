# list_formats

What this workspace can make. Returns the workspace's OWN design collections (workflows/<collection>/) — their families (ad, carousel, story…), the .comp shells hydrate_template can fill, the canvas and the shot limits — plus the shared template library. Call this FIRST for "make me a layout/ad/story"; it answers in one call what reading a collection's system.md answers in ten, and the workspace's own collections beat the shared library because they already carry the brand's canvas and slots.
