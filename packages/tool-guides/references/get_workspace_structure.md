# get_workspace_structure

Get a tree of the workspace directory structure. Use ONLY when the question is itself about the layout — "what is in here", "how is this organised", "where do things live". Do NOT call it as a first step before doing something else: publishing, scheduling, editing a shot, removing a background, generating, or opening a piece all have their own tool, and each takes a path or a name directly. If you lack the path, that tool will say so, and one failed call costs less than a directory survey the user did not ask for. Never open a turn with this to see where you are.

## Parameters

### maxDepth — number

Max depth of directory tree (default: 3).
