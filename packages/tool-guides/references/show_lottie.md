# show_lottie

Play a Lottie animation from the workspace in the conversation, with the app transport. Use when the user wants to WATCH a Lottie (a .json animation) rather than be told where it is; a path alone shows nothing. Takes Lottie JSON — a .lottie (dotLottie zip) must be exported to JSON first.

## Parameters

### path — string (required)

Workspace-relative path to the Lottie JSON file.
