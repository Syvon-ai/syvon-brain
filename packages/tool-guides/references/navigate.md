# navigate

Switch the studio to a different SECTION when the user asks to go somewhere — e.g. "go to flow", "open brand", "take me to settings", "back to canvas". Sections: agent (home), canvas (compositions), brand, flow (the board), live (preview), settings. ALWAYS use this for navigation requests — do NOT open or create a file to move the user.

## Parameters

### section — string (required)

The section to switch to.
