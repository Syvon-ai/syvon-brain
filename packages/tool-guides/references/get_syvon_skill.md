# get_syvon_skill

Read this FIRST when you are unsure how Syvon fits together. Returns a short architecture brief: how projects, compositions (.comp), shots, designs (.dsgn), components (.react) and slots relate, where copy lives (and which tool edits it), the payload-size limits, and how to check and ship. One read instead of inferring the model from trial and error. Pass `topic` to get the playbook for the thing you are about to make in the SAME call — one of: deck, motion, social, print, interactive, layout, text, brand, fixing, vocabulary, routing, anti-slop, motion-craft, motion-doctrine, loops, delivery, captions, post, sonic, copy. Do that before authoring a deck, a motion piece, a carousel or a document: the playbook carries the canonical .comp shape, the shot counts and the failures specific to that kind, which the brief alone does not.

## Parameters

### topic — string

Optional. Appends the playbook for that kind of work to the brief. Use the one matching what you are about to make or fix.
