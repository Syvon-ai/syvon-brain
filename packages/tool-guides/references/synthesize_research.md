# synthesize_research

Synthesize multiple text sources into a structured summary. Use after search_web and browse_url to create coherent summaries.

## Parameters

### text_inputs — array (required)

Array of text blobs to synthesize.

### synthesis_format — string

Desired output format (e.g., "bulleted list", "comparison table", "300-word summary").

### focus_question — string

Specific question or focus area for the synthesis.
