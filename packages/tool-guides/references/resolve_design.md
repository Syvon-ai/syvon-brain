# resolve_design

Re-settle a design's measurable decisions against the images it points at — today, whether each Asset should cover or contain its frame. Run it after swapping a brand, changing an image, or moving a design between workspaces, when the layout looks subtly wrong (things cropped or letterboxed) but nothing was moved. Never changes structure, copy or position; safe to run twice.

## Parameters

### path — string (required)

The .dsgn file to resolve.

### dryRun — boolean

Report what would change without writing. Default false.
