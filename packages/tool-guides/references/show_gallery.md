# show_gallery

Show several workspace items at once as a grid of stills — designs, compositions, videos and images together. Use when the user wants to SEE a set or compare options rather than open one thing (read_design / read_comp / show_video open a single item full-size). Designs render as composed stills; comps and videos show their poster; components show a tile. Pass up to 24 paths.

## Parameters

### paths — array (required)

Workspace-relative paths to show, in order.

### title — string

Optional heading for the grid.
